skunk.club turns a CS2 demo into a 3D replay in the browser. Nothing to install and no account needed. There are three ways in, depending on what you have.

You have a demo file

  1. Open the home page.
  2. Press Upload a demo, or drop the file anywhere on the page. It takes .dem, .dem.bz2 and .dem.gz files, one at a time.
  3. Wait for the progress bar. A big demo goes up in chunks, and if one fails you can retry from that chunk.
  4. When the upload is done the page moves to the replay, which opens once the demo has been parsed. If the site already holds the same demo, it opens straight away.

You have a share code or a link

Paste a share code (it starts with CSGO-), a CS2 share link or a Valve replay link into the box on the home page and press Watch replay. The site fetches the demo from Valve and opens it. Valve deletes replays after 30 days, so for an older match you need the demo file itself.

You have a FACEIT match

A FACEIT match room link goes in the same box. FACEIT demos sometimes have to be uploaded, so see how to watch a FACEIT demo in 3D.

Good to know

Uploaded matches appear on their players' profiles, and profiles and matches are public. If you would rather a profile was hidden, the contact page says how to ask.
